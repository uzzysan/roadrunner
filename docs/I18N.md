# RoadRunner i18n - System Wielojęzyczny

## Architektura

### Backend (Rust)
- **Biblioteka**: `fluent` lub `rust-i18n`
- **Format**: YAML lub JSON
- **Lokalizacja**: `/locales/{lang}/`

### Frontend (React/React Native)
- **Biblioteka**: `i18next` + `react-i18next`
- **Format**: JSON
- **Lokalizacja**: `/locales/{lang}/`

## Klucze Tłumaczeń

### Konwencje Nazewnictwa
- Używaj notacji `snake_case`
- Grupuj powiązane klucze (np. `auth.login`)
- Używaj zagnieżdżonych obiektów dla lepszej organizacji

### Przykłady
```json
{
  "auth": {
    "login": "Zaloguj się",
    "register": "Zarejestruj się"
  },
  "validation": {
    "email_required": "Email jest wymagany"
  }
}
```

## Użycie w Kodzie

### Backend (Rust)
```rust
use crate::i18n::I18n;

let i18n = I18n::new("pl");
let message = i18n.t("auth.login");
```

### Frontend (React)
```tsx
import { useTranslation } from 'react-i18next';

function LoginButton() {
  const { t } = useTranslation();
  return <button>{t('auth.login')}</button>;
}
```

## Dodawanie Nowego Języka

1. Utwórz folder `/locales/{lang}/`
2. Skopiuj pliki z `/locales/en/`
3. Przetłumacz wszystkie wartości
4. Dodaj język do konfiguracji i18n
5. Dodaj flagę w UI

## Formatowanie

### Daty
- **PL**: `dd.MM.yyyy HH:mm`
- **EN**: `MM/dd/yyyy h:mm a`

### Waluty
- **PL**: `99,99 zł`
- **EN**: `$99.99`

### Liczby
- **PL**: `1 234,56`
- **EN**: `1,234.56`

## Zarządzanie Tłumaczeniami

### Narzędzia
- **Crowdin** - profesjonalne zarządzanie
- **GitLocalize** - integracja z GitHub
- **Manual** - edycja JSON

### Proces Tłumaczenia
1. Dodaj nowe klucze w języku źródłowym (EN)
2. Powiadom tłumaczy
3. Przejrzyj i zatwierdź tłumaczenia
4. Zmerge'uj do main

## Walidacja

Sprawdź kompletność tłumaczeń:
```bash
# Sprawdź czy wszystkie klucze są przetłumaczone
npm run i18n:validate
```
