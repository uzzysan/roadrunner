# RoadRunner Mobile App

React Native + Expo + React Native Paper

## Features
- 📱 Bottom tab navigation
- 🌗 Dark/Light theme support
- 🎨 Material Design 3
- 🔴 Brand colors (red bus, navy, yellow accent)

## Screens
- **Home** - Dashboard z szybkimi akcjami
- **Tickets** - Bilety QR
- **Tracking** - Śledzenie GPS autobusów
- **Profile** - Profil użytkownika

## Run
```bash
npm install
npx expo start
```

Scan QR code with Expo Go app on your phone.
